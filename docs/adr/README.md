# Architecture Decision Records

One file per significant decision: `NNNN-short-title.md` (e.g. `0001-monorepo-npm-workspaces.md`).
An ADR is never edited after it's accepted; a new ADR supersedes it.

## Template

```markdown
# NNNN. Title

- Status: Proposed | Accepted | Superseded by NNNN
- Date: YYYY-MM-DD

## Context
What problem are we solving? What constraints exist?

## Decision
What we chose.

## Consequences
What gets easier, what gets harder, what we must now do.

## Alternatives considered
Option — why not.
```
